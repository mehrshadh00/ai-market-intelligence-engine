# موتور هوشمند تحلیل بازار و شناسایی فرصت‌های فروش

یک گردش‌کار مبتنی بر هوش مصنوعی برای تحقیق درباره محصول، تحلیل بازار، شناسایی مشتریان بالقوه، رتبه‌بندی آن‌ها با معیارهای قابل توضیح و آماده‌سازی ایمیل‌های فروش شخصی‌سازی‌شده.

## قابلیت‌ها

- تحقیق وب با استفاده از OpenAI API و ابزار جست‌وجوی وب
- بررسی ادعاهای بدون پشتوانه و شناسایی کمبود شواهد
- تحلیل بازار و رقبا
- شناسایی مشتریان بالقوه
- امتیازدهی قطعی و قابل تنظیم به مشتریان
- تولید پیش‌نویس ایمیل فروش و امکان ارسال اختیاری از طریق SMTP
- تست واحد برای امتیازدهی، شواهد ناقص و شکستن تساوی امتیازها

## معماری کلی

```text
شرح محصول
    ↓
تحقیق وب → ارزیابی شواهد
    ↓
تحلیل بازار → شناسایی مشتریان بالقوه
    ↓
امتیازدهی قطعی → رتبه‌بندی مشتریان
    ↓
تولید ایمیل → ارسال اختیاری از طریق SMTP
```

## فناوری‌ها

Python · Streamlit · OpenAI Responses API · Pydantic · python-dotenv · Pytest · SMTP

## راه‌اندازی

### ۱. ساخت محیط مجازی

**macOS / Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

**Windows PowerShell**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### ۲. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### ۳. تنظیم متغیرهای محیطی

فایل `.env.example` را به `.env` کپی کنید و کلید API خودتان را در فایل محلی `.env` قرار دهید:

```dotenv
OPENAI_API_KEY=your_openai_api_key
OPENAI_MODEL=gpt-4.1-mini
```

تنظیمات SMTP اختیاری هستند و فقط برای ارسال ایمیل کاربرد دارند. برای Gmail از App Password استفاده کنید، نه رمز عبور اصلی حساب.

### ۴. اجرای برنامه

```bash
streamlit run app.py
```

### ۵. اجرای تست‌ها

```bash
python -m pytest -v
```

## منطق امتیازدهی مشتریان

امتیاز مشتریان در Python و بر اساس پنج معیار محاسبه می‌شود:

- ارتباط با صنعت هدف
- تطابق جغرافیایی
- شواهد پشتیبان
- ارتباط تجاری با محصول
- وجود نشانی وب‌سایت

این روش قطعی و قابل بررسی است؛ بنابراین برخلاف امتیازدهی مستقیم توسط مدل زبانی، نتایج آن راحت‌تر قابل توضیح و آزمون هستند. معیار وب‌سایت فقط وجود نشانی URL را بررسی می‌کند و دسترس‌پذیری زنده یا آنلاین بودن سایت را نمی‌سنجد. نبود شواهد یا تأیید نشدن آن، امتیاز مثبت محسوب نمی‌شود.

## نکات امنیتی

- هرگز فایل `.env`، کلیدهای API، اطلاعات SMTP یا داده‌های خصوصی را در GitHub منتشر نکنید.
- اطلاعات تحقیق‌شده و مشتریان بالقوه را پیش از استفاده بررسی کنید.
- پیش از ارسال، متن ایمیل و نشانی گیرنده را بازبینی کنید.
- استفاده از API ممکن است هزینه داشته باشد.
